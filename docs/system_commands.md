# Команды 1С:Предприятие 7.7 (WM_COMMAND)

Собрано скриптом `docs/extract_commands.py` из ресурсов платформы в `BIN` (меню, ускорители, строки подсказок) и из меню, снятых с работающей 1С в разных режимах (`docs/menus_live.json`, скрипт `docs/menu_dump.py`). Команду можно послать главному окну 1С: `SendMessage(главное окно, WM_COMMAND, код, 0)` — так работают `ОткрытьСистемноеОкно()` и инструмент MCP `system_command`. Действует команда на активное окно (MDI): «Сохранить», «Копировать», «Движения документа» относятся к тому окну, что сейчас активно.

**Режим** — в каком режиме 1С эта команда есть в меню:

- без звёздочки — пункт виден в живом меню этого режима (снято с тест-базы);
- со звёздочкой (`Предприятие*`) — пункт есть в меню-ресурсе, которое совпадает с меню этого режима, но в снятых окнах его не было (меню другого вида окна: документ, журнал, редактор модуля и т.п.);
- `?` — меню-ресурс не удалось сопоставить ни с одним снятым меню (контекстные меню, редкие окна).

Режим меню — это где пункт показан, а не где команда может сработать. Обработчики многих команд общие: например, 32854 «Пользователи» есть только в меню Конфигуратора, но, посланная в режиме Предприятия, открывает список пользователей, и его можно править без Конфигуратора. Команды Конфигуратора, меняющие конфигурацию, в Предприятии посылать не стоит.

**Источник** — файл платформы и номера меню-ресурсов, где есть пункт. Почти все меню лежат в `1crcrus.dll` (русские ресурсы, общие для всех режимов), Конфигуратор добавляет `config.dll`.

FormEx в `ПриПолученииКоманды` отдаёт некоторые коды со старшим битом: 99298 = 65536 + 33762 («Включить проводки», F8), 123170 = 65536 + 57634 («Копировать»).
