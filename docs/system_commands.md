# Команды 1С:Предприятие 7.7 (WM_COMMAND)

Собрано скриптом `docs/extract_commands.py` из ресурсов платформы в `BIN` (меню, ускорители, строки подсказок). Команду можно послать главному окну 1С: `SendMessage(главное окно, WM_COMMAND, код, 0)` — так работает `ОткрытьСистемноеОкно()`. Действует команда на активное окно (MDI): «Сохранить», «Копировать», «Движения документа» относятся к тому окну, что сейчас активно.

FormEx в `ПриПолученииКоманды` отдаёт некоторые коды со старшим битом: 99298 = 65536 + 33762 («Включить проводки», F8), 123170 = 65536 + 57634 («Копировать»).

Пунктов меню: 422. Если путь у команды разный в разных окнах, показаны до трёх вариантов.
